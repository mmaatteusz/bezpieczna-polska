# Bezpieczna Polska 0.1.0-beta.1

Pierwsza beta Android. Zbieramy uwagi z codziennego korzystania; aplikacja nie jest państwowym systemem alarmowym. Brak komunikatów nie gwarantuje bezpieczeństwa.

## Zmiany

- Prostszy Start: sytuacja w wybranej miejscowości, do trzech najważniejszych komunikatów i przyciski otwarcia mapy oraz wszystkich alertów. Zmiana miejscowości jest dostępna bezpośrednio na ekranie.
- Status Polski, stopnie alarmowe i opis zakresu danych są rozwijane. Krytyczne zagrożenie krajowe pozostaje widoczne bez rozwijania. Tryb offline i brak świeżych danych pozostają oznaczone.
- UkraineAlarm: zniknięcie alarmu z bieżącego feedu nie wysyła już powiadomienia „Zakończenie”. Historia nadal pokazuje tę zmianę z informacją, że dokładny czas nie jest znany. Już oczekujące wiadomości tego rodzaju są odrzucane przed wysyłką.
- Kolejka push ponownie sprawdza aktualne preferencje urządzenia. Wyłączenie kategorii zatrzymuje jej oczekujące wiadomości i ponowienia.
- Ikony NEPTUN pozostają widoczne po oddaleniu mapy; nakładające się punkty otwierają wybór wpisu.
- README opisuje bieżącą architekturę Oracle, PostgreSQL/PostGIS, konfigurację Firebase i sposób sprawdzania push.
- Numeracja przechodzi na beta; kolejne automatyczne podbicia pozostają w tym kanale.

## Instalacja i powiadomienia

APK jest przeznaczony dla Androida ARM64 (Android 7 lub nowszy), ma pakiet `pl.bezpiecznapolska.preview` i trwały podpis preview. Można nim aktualizować dotychczasowe APK preview z tym samym podpisem, zachowując dane. To wydanie beta w GitHub Releases; nie oznacza publikacji w Google Play. Numer `+78` w źródłach jest numerem kanonicznym; instalowalne preview używa wyższego, rosnącego Android `versionCode` z CI.

APK zawiera konfigurację Firebase Cloud Messaging i korzysta z API Oracle: https://bezpieczna-polska-api.duckdns.org. Backend tego samego commita jest wdrażany przed publikacją. Obsługa FCM w buildzie nie jest potwierdzeniem odebrania powiadomienia na każdym telefonie: po instalacji użyj testu w ustawieniach powiadomień.

Alarmy Ukrainy są osobną, domyślnie wyłączoną kategorią obejmującą całą Ukrainę. Nie wpływają na status Polski. Zakres danych źródeł i geometrii pozostaje częściowy; pełny podkład mapy nie jest częścią pakietu offline.

Do wydania dołączamy `SHA256SUMS.txt`, metadane pakietu i wynik weryfikacji podpisu. Zgłaszając problem, podaj model telefonu, wersję Androida i numer buildu z ustawień.
